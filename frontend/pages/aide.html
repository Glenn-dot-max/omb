🛒 Commandes

La page Commandes est le cœur de l'application. Elle liste toutes les commandes de votre franchise.

Créer une commande

1
Cliquer sur ➕ Nouvelle commande
2
Renseigner le nom du client (min. 2 caractères)
3
Choisir la date et l'heure de livraison
4
Indiquer le nombre de couverts et le type de prestation
5
Valider — la commande apparaît dans la liste
💡 Une commande en doublon (même client, même date, même heure) est automatiquement bloquée.

Filtres et recherche

  • Rechercher par nom de client via la barre de recherche
  • Filtrer par date : aujourd'hui, demain, cette semaine
  • Basculer entre Commandes actives et Commandes archivées

Archiver une commande

Une commande archivée reste accessible dans l'onglet "Archivées" mais ne figure plus dans le planning de production.

📦 Produits

Les produits constituent le catalogue de base. Ils sont ensuite regroupés dans des formules.

Ajouter un produit FranchiseAdmin

  • Nom du produit (doit être unique dans votre franchise)
  • Catégorie (sucré, salé, boisson…)
  • Type (viennoiserie, fruit, fromage…)
💡 Si un produit a été désactivé par le passé, le recréer avec le même nom le réactivera automatiquement.

Catalogue global Admin uniquement

Le TECH_ADMIN gère un catalogue global. Un produit créé par l'admin peut être activé pour toutes les franchises ou seulement certaines.

🍳 Formules

Une formule regroupe des produits avec des quantités par couvert. Elle est ensuite associée à une commande.

Créer une formule

1
Cliquer sur + Créer une formule
2
Nommer la formule et choisir son type (Brunch, Non-brunch, Mariage…)
3
Ajouter des produits et définir la quantité par couvert pour chacun
4
Valider

Recherche et filtres

  • Recherche par nom de formule
  • Filtre par type de prestation
  • Filtre par franchise Admin

📊 Planning de Production

Le planning agrège les commandes sur une période et calcule les quantités totales à produire par produit.

Générer le planning

1
Choisir une date de début et une date de fin
2
Filtrer par type de prestation et/ou catégorie de produit si besoin
3
Cliquer sur 🔄 Générer le planning

Exporter en Excel

Une fois le planning généré, le bouton 📥 Exporter en Excel apparaît. Le fichier Excel est généré directement dans le navigateur (pas d'envoi au serveur) et téléchargé automatiquement.

💡 Le planning est calculé en heure de Paris (Europe/Paris), quelle que soit votre timezone.

Filtre franchise Admin uniquement

Le TECH_ADMIN peut générer un planning toutes franchises confondues ou filtrer par franchise spécifique.

👤 Mon compte

  • Accès via le menu utilisateur en haut à droite
  • Voir son email, franchise associée et rôle
  • Changer son mot de passe via Changer mon mot de passe

Règles du mot de passe

  • Minimum 8 caractères
  • La confirmation doit correspondre

🔧 Administration TECH_ADMIN uniquement

La page Admin est accessible uniquement aux comptes TECH_ADMIN. Elle permet de gérer les franchises et les utilisateurs.

Franchises

  • Créer une nouvelle franchise (nom, ville, email, téléphone)
  • Modifier ou désactiver une franchise existante

Utilisateurs

  • Créer un compte utilisateur et l'associer à une franchise
  • Définir le rôle : USER (accès franchise uniquement) ou TECH_ADMIN (accès global)
  • Activer / désactiver un compte
  • Réinitialiser le mot de passe d'un utilisateur
⚠️ Un utilisateur désactivé ne peut plus se connecter même avec un token JWT valide.
